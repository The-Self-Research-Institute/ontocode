1. Overview

The Graph View Plugin provides D3.js-powered graph visualization with hierarchical lazy loading, WebVOWL notation, smart search, path visualization, and 60 FPS performance targeting 100,000+ nodes.

Key Components Under Test

  • GraphViewSidebar.tsx — Entity selector, filters, statistics panel
  • MatrixView.tsx — Adjacency matrix visualization
  • StatsDashboard.tsx — Real-time ontology metrics
  • UnifiedSidebar.tsx — Consolidated sidebar UI

Key Services Under Test

  • GraphDataFetchService.ts — Data fetching from GraphDB with lazy loading
  • GraphDataService.ts — Caching and synchronization (5-min TTL)
  • GraphMutationService.ts — Graph modification with optimistic updates
  • VOWLNotationService.ts — VOWL-compliant visual representation

API Endpoints

MethodEndpointDescription
GET/api/ontology/{projectId}/graphFetch graph data
POST/api/ontology/{projectId}/graph/nodesCreate node
PUT/api/ontology/{projectId}/graph/nodes/{nodeId}Update node
POST/api/collab-graph/{projectId}/clear-cacheClear backend cache

  • Validate deterministic ranking and tie handling.
  • Validate reasoner integration under inferred fuzzy relationships.
  • Validate performance when fuzzy annotations increase graph density.

Fuzzy Membership Functions

This subsection validates correct computation of membership functions that determine how strongly an input value belongs to a fuzzy set. Membership functions map real-world values to degrees of membership in the range [0,1].

TC-FZ-001: Triangular Membership Function

Verify triangular membership function computes correct membership degrees for input values

Function Definition

A triangular membership function is defined by three parameters: a (left foot), b (peak), and c (right foot). The membership degree μ(x) varies as follows:

  • For x ≤ a or x ≥ c: μ(x) = 0 (outside range, no membership)
  • For a < x ≤ b: μ(x) = (x − a) / (b − a) (linear rise to peak)
  • For b < x < c: μ(x) = (c − x) / (c − b) (linear fall from peak)
  • For x = b: μ(x) = 1.0 (maximum membership at peak)

Test Configuration

  • Fuzzy Set Name: "Moderate"
  • Function Type: Triangular
  • Parameters: a=20 (left), b=50 (peak), c=80 (right)

Test Inputs and Expected Results

Input (x) Expected μ(x) Computation Explanation
20 0.0 At left foot a=20: boundary point, no membership (x = a, not < a)
35 0.5 Midpoint between a and b: (35 − 20) / (50 − 20) = 15 / 30 = 0.5 (halfway to peak)
50 1.0 At peak b=50: maximum membership degree = 1.0
65 0.5 Midpoint between b and c: (80 − 65) / (80 − 50) = 15 / 30 = 0.5 (halfway down from peak)
80 0.0 At right foot c=80: boundary point, no membership (x = c, not < c)
90 0.0 Beyond right foot: x > c, so μ(x) = 0.0 (completely outside fuzzy set)

Membership Degree Behavior Explanation

Why these degrees? The triangular membership function models a linear, symmetric change in membership around a peak value. Here's the intuition:

  • x = 20 (left foot): At the boundary, membership begins to transition from "no membership" (x < 20) to "some membership" (x > 20). At exactly x = 20, we treat it as 0.0 to reflect the semantic boundary.
  • x = 35 (halfway to peak): This value is 15 units above the left foot (20) and 15 units below the peak (50). The linear interpolation gives (35−20)/(50−20) = 0.5, meaning "moderate membership"—halfway between no membership and full membership.
  • x = 50 (peak): At the peak, the concept "Moderate" is most representative
  • x = 65 (halfway down): By symmetry with x = 35, the value 65 is 15 units below the peak (50) and 15 units above the right foot (80). The linear fall gives (80−65)/(80−50) = 0.5, the same membership degree as the upslope side.
  • x = 80 (right foot): At the right boundary, membership ends. Treatment is identical to x = 20: membership is 0.0 at the exact boundary point.
  • x = 90 (beyond range): Outside the interval [20, 80], the value has zero membership in "Moderate". A value of 90 is too high and would belong to a different fuzzy set (for example, "High" if defined as (70, 95, 120)).

Steps

  1. Open Fuzzy Editor in ontology framework
  2. Create a new fuzzy class named "Moderate"
  3. Select membership function type "Triangular"
  4. Set parameters: a=20, b=50, c=80
  5. For each input value (20, 35, 50, 65, 80, 90), invoke the membership function and record the returned μ(x)
  6. Compare computed values against Expected Results table

Expected Results

  • All six inputs produce membership degrees matching the table above (within tolerance 0.001)
  • Membership degree graph is smooth, continuous, and symmetric around peak
  • No rounding artifacts or numerical instability
  • Serialized membership function preserves parameter precision (a, b, c not truncated)

Scenario Explanation

Triangular membership functions are the most commonly used in production ontologies because they are computationally efficient and semantically intuitive. This test validates correct math (linear interpolation without errors), boundary handling (feet at 0.0, peak at 1.0), and symmetry (equal distance from peak produces equal membership). Failures here affect all downstream fuzzy classification, ranking, and reasoning—making this a critical validation before deployment.

TC-FZ-002: Trapezoidal Membership Function

Verify trapezoidal membership function correctly models a plateau region (not just a peak)

Function Definition

A trapezoidal membership function extends the triangle by adding a plateau where membership = 1.0. Defined by four parameters: a (left foot), b (left plateau), c (right plateau), d (right foot):

  • For x ≤ a or x ≥ d: μ(x) = 0
  • For a < x ≤ b: μ(x) = (x − a) / (b − a) (rise)
  • For b < x < c: μ(x) = 1.0 (plateau)
  • For c ≤ x < d: μ(x) = (d − x) / (d − c) (fall)

Test Configuration

  • Fuzzy Set Name: "Warm"
  • Function Type: Trapezoidal
  • Parameters: a=15, b=25, c=75, d=85

Test Inputs and Expected Results

Input (x) Expected μ(x) Region

150.0Left foot boundary
200.5Linear rise: (20−15)/(25−15) = 0.5
251.0Left plateau start
501.0Inside plateau (mid-range)
751.0Right plateau end
800.5Linear fall: (85−80)/(85−75) = 0.5
850.0Right foot boundary
900.0Above right foot

Steps

  1. Create fuzzy class "Warm" with trapezoidal function
  2. Set parameters: a=15, b=25, c=75, d=85
  3. Test all nine inputs above and record membership degrees
  4. Verify plateau region (x ∈ [25, 75]) consistently returns 1.0
  5. Verify symmetry: (20, 0.5) on rise mirrors (80, 0.5) on fall

Expected Results

  • Rise and fall slopes are correct: 1/10 = 0.1 per unit
  • Plateau region has zero slope; all values ∈ [25,75] return μ = 1.0
  • Symmetric slopes on rise and fall
  • No discontinuities at b and c transitions

Scenario Explanation

Trapezoidal functions model concepts with a range of ideal values, not just a single peak (e.g., "warm temperature" = 25°C to 75°C ideal). This test validates the plateau logic and confirms that the function correctly distinguishes transition zones (rise/fall) from ideal zones (plateau).

TC-FZ-003: Gaussian Membership Function

Verify Gaussian (bell-curve) membership function computes smooth, non-linear degree transitions

Function Definition

A Gaussian membership function models smooth, bell-shaped transitions using the normal distribution formula: μ(x) = exp(−((x − μ₀)² / (2σ²))), where μ₀ is the mean (peak) and σ is the standard deviation (width):

  • At x = μ₀: μ(x) = 1.0 (peak)
  • At x = μ₀ ± σ: μ(x) ≈ 0.606 (inflection points)
  • At x = μ₀ ± 2σ: μ(x) ≈ 0.135 (tail)
  • At x = μ₀ ± 3σ: μ(x) ≈ 0.011 (far tail)

Test Configuration

  • Fuzzy Set Name: "Normal"
  • Function Type: Gaussian
  • Parameters: μ₀=50 (mean), σ=10 (std dev)

Test Inputs and Expected Results

Input (x) Expected μ(x) Explanation
501.000Peak: exp(0) = 1.0
400.606At μ₀ − σ: exp(−0.5) ≈ 0.606
600.606At μ₀ + σ: exp(−0.5) ≈ 0.606 (symmetry)
300.135At μ₀ − 2σ: exp(−2) ≈ 0.135
700.135At μ₀ + 2σ: exp(−2) ≈ 0.135 (symmetry)
200.011At μ₀ − 3σ: exp(−4.5) ≈ 0.011 (far tail)

Steps

  1. Create fuzzy class "Normal" with Gaussian function
  2. Set parameters: μ₀=50, σ=10
  3. Test all six inputs and record membership degrees
  4. Verify symmetry: values equidistant from peak have identical degrees
  5. Plot membership degree curve; verify smooth bell shape without discontinuities

Expected Results

  • All computed degrees match expected values (tolerance ±0.01)
  • Perfect symmetry around peak: μ(50±x) = μ(50∓x)
  • Smooth curve; no jumps or flat regions
  • Tail values approach 0.0 but never reach exactly 0.0

Scenario Explanation

Gaussian functions model probabilistic confidence and smooth uncertainty better than triangular functions. They represent natural phenomena (e.g., measurement noise, normal distributions in sensor data). This test validates numerical stability of the exponential calculation and confirms correct parameter interpretation.

TC-FZ-006: T-norm and T-conorm Operations

Verify fuzzy conjunction (AND) and disjunction (OR) operations produce mathematically correct results

Function Definitions

Fuzzy logic uses t-norms (AND) and t-conorms (OR) to combine membership degrees:

  • Intersection (AND): μ_A ∩ B(x) = min(μ_A(x), μ_B(x))
  • Union (OR): μ_A ∪ B(x) = max(μ_A(x), μ_B(x))
  • Complement (NOT): μ_¬A(x) = 1 − μ_A(x)
  • Algebraic Product (AND alt): μ_A(x) × μ_B(x)
  • Algebraic Sum (OR alt): μ_A(x) + μ_B(x) − μ_A(x) × μ_B(x)

Test Configuration

  • Set A: "Hot" with μ_A = 0.7
  • Set B: "Dry" with μ_B = 0.4

Test Cases and Expected Results

Operation Formula Computation Expected Result
Intersection (min) min(μ_A, μ_B) min(0.7, 0.4) 0.4
Union (max) max(μ_A, μ_B) max(0.7, 0.4) 0.7
Complement of A 1 − μ_A 1 − 0.7 0.3
Algebraic Product μ_A × μ_B 0.7 × 0.4 0.28
Algebraic Sum μ_A + μ_B − (μ_A × μ_B) 0.7 + 0.4 − 0.28 0.82
De Morgan's Law 1 ¬(A ∩ B) = ¬A ∪ ¬B 1 − min(0.7, 0.4) = max(0.3, 0.6) 0.6 (verified both sides)
De Morgan's Law 2 ¬(A ∪ B) = ¬A ∩ ¬B 1 − max(0.7, 0.4) = min(0.3, 0.6) 0.3 (verified both sides)

Steps

  1. Define two fuzzy sets with given membership degrees
  2. Compute all operations above using the fuzzy system
  3. Compare results against expected values
  4. Verify De Morgan's laws hold (equality on both sides)
  5. Test with various degree combinations: (0, 0), (1, 1), (0.5, 0.5), (0.1, 0.9)

Expected Results

  • All min/max operations match expected values exactly
  • Algebraic operations accurate to tolerance ±0.001
  • De Morgan's laws verified: ¬(A ∩ B) = ¬A ∪ ¬B and ¬(A ∪ B) = ¬A ∩ ¬B
  • Complement operation: μ_¬A + μ_A = 1.0 (always true)
  • All results in valid range [0.0, 1.0]

Scenario Explanation

T-norm and t-conorm operations are the foundation of fuzzy rule inference (e.g., "IF (Hot AND Dry) THEN..." requires AND operation). Failures here silently corrupt downstream reasoning. This test ensures logical consistency and prevents subtle inference bugs that are hard to debug.
