# Ontology Change Assistant Plugin

Assists in tracking and managing collaborative ontology edits with comprehensive change history, conflict detection, and version control integration.

## Features

- **Change Tracking**: Automatically tracks all ontology modifications with detailed change history
- **Conflict Detection**: Identifies and highlights potential conflicts in collaborative editing scenarios
- **Change Review**: Review and approve/reject changes before they are committed
- **Diff Visualization**: Visual comparison of ontology versions showing additions, deletions, and modifications
- **Collaboration Tools**: Comment on changes, tag collaborators, and discuss modifications
- **Version Integration**: Integrates with Git and other version control systems
- **Change Analytics**: Statistics and insights about editing patterns and contributors
- **Rollback Support**: Easy rollback to previous versions with conflict resolution
- **Merge Assistant**: Intelligent merging of parallel edits with conflict resolution suggestions

## Usage

1. Install the plugin through the OntoCode plugin manager
2. Open any OWL ontology file
3. The Change Assistant panel will appear in the side panel
4. All changes are automatically tracked and displayed in real-time
5. Review changes, resolve conflicts, and commit approved modifications

## Change Types Tracked

- Class additions, deletions, and modifications
- Property additions, deletions, and modifications
- Individual additions and modifications
- Axiom changes
- Annotation changes
- Import statement changes

## Collaboration Features

- Real-time change notifications
- User attribution for all changes
- Change comments and discussions
- Conflict highlighting and resolution workflows
- Merge request reviews

## Version Control Integration

- Git integration for commit history
- Branch comparison and merging
- Pull request change summaries
- Automatic conflict detection from VCS
