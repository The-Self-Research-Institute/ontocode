
# 🚀 Get Started in 30 Seconds

## 🐳 No Node.js? No Problem!

**Docker-Only Mode** (Only Docker required):
```cmd
docker-install.bat
```
Opens at http://localhost:3000

## 💻 Have Node.js? Even Better!

**Hybrid Mode** (Docker + Node.js):
```cmd
install-and-run.bat
```
Auto-opens in your browser with hot-reload

## 🤔 Not Sure?

Just run this - it auto-detects the best mode:
```cmd
install-and-run.bat
```
